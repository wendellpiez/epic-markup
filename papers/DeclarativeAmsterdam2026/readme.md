
# What can we see when we can see overlap?

**Modeling Homer's Iliad with exploratory markup: A MNML LMNL case study**

Declarative Amsterdam 2026

The paper presents the idea of **exploratory markup** and explains how free-form markup using LMNL (the Layered Markup and Annotation Language) can enrich the study of Homer's *Iliad*.
